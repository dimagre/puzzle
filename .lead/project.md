# PuzzleShare

## What
Web platform for renting and exchanging jigsaw puzzles in Ukraine.

## Target User
Puzzle enthusiasts in Ukraine who want access to variety without buying every puzzle.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript strict
- Prisma + PostgreSQL
- Tailwind CSS + shadcn/ui
- Auth.js v5
- Vercel Blob (images)

## Current Phase
Early development — scaffold committed, no features shipped yet.

## Hard Constraints
- Currency: UAH only
- Bilingual: uk/en
- Mobile-first
- Admin-only puzzle creation in MVP
- No free puzzles in MVP

## Cost Thresholds (defaults until owner sets)
- Recurring: $20/month
- One-time: $100
